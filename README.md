# KV16 — Tomb of Ramesses I

Interactive WebGL2 tour of the Tomb of Ramesses I (KV16).

## Run locally

Open `index.html` in a modern browser. If your browser blocks local assets, run a local static server from this folder (for example: `python -m http.server 8000`) and visit `http://localhost:8000`.

## Deploy with GitHub Pages

1. Upload **all files and the `audio/` folder** in this package to the repository root on `main`.
2. In **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
3. Wait for the Pages deployment to finish.

The entry page is `index.html`; `images.js` and `audio/` must stay beside it / at the same relative paths.
